# Job Search — AI-Powered Job Hunting System

Проект для системного поиска работы разработчиком, где весь процесс делегирован AI-агентам.

**Роль владельца:** контролирующий архитектор — ставлю задачи агентам, проверяю целостность и соответствие спецификациям.

## Карта проекта

| Модуль | Назначение | Статус |
|--------|------------|--------|
| [`about_me/`](about_me/) | Профиль, pitch, ставки | 🟡 skeleton |
| [`portfolio/`](portfolio/) | Проекты для портфолио | 🔴 empty |
| [`sources/`](sources/) | Каталог источников вакансий | 🔴 empty |
| [`parsers/`](parsers/) | Боты/парсеры платформ | 🔴 empty |
| [`monitoring/`](monitoring/) | Мониторинг и алерты | 🔴 empty |
| [`outreach/`](outreach/) | Коммуникации и шаблоны | 🔴 empty |
| [`packaging/`](packaging/) | Упаковка: CV, LinkedIn, сайт | 🔴 empty |
| [`pipeline/`](pipeline/) | Оркестрация всего процесса | 🔴 empty |
| [`analytics/`](analytics/) | Воронка, статистика, выводы | 🔴 empty |

## Точки входа

- **Для человека:** этот `README.md`
- **Для AI-агента:** [`AGENTS.md`](AGENTS.md)

## Принцип работы

1. **Спецификация** → описываем что нужно сделать в `.md`
2. **Реализация** → AI-агент пишет код/контент по спецификации
3. **Верификация** → проверяем соответствие результата спецификации
4. **Консистентность** → изменения в `about_me/` отражаются во всех модулях
